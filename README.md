# Metroidvania Proyect
Prototipo de videojuego del género Metroidvania utilizado para encontrar métricas que ayuden a verificar si los estándares usados son válidos
para una experiencia de usuario satisfactoria para el jugador.

## Estándares utilizados
Para la definición de movimiento se usó el "Game Feel" implementado for los desarrolladores de Celeste, que ha sido popular en cuanto a tener una 
sensación de movimiento satisfactoria.

Para diseño de Nivel se siguieron varias prácticas de Hollow Knight y Blasphemous.

## Desarrollo y objetivos
Este prototipo fue utilizado para mi proyecto de tesis, realizado en Unity
